# Four-language UI and provisioning About — 0.0.1 / 2026-09-05

Supersedes the current candidate in [product branding](2026-09-05-product-branding.md),
without rewriting earlier evidence. Source is the initial uncommitted workspace
on unborn `main`, not a published tag. Root `VERSION` remains 0.0.1.

## Changes

- Both setup and success Web pages show product, version, repository, author,
  Wi-Fi-only setup scope, and the open-hotspot ten-minute security boundary.
  Metadata is public-only; no credentials or personal usage are exposed.
- Settings: `Reset Settings` and a new Language row. OK cycles English,
  Simplified Chinese, Traditional Chinese, Japanese, then English.
- English is the default, including existing installations without a language
  key. `vibe_cfg/language_v1` is a separate byte; the CRC-protected schema-1
  settings blob, identity, auth and schema-2 usage cache are unchanged.
- Commit-before-publish language updates do not restart account/data clients.
  Note performs a full refresh; the next portal session takes the saved language.
  Language save errors leave the language unchanged and show a footer error.
- Bundled translated copy uses 211 messages and 470 CJK glyphs. Note draws
  16px 1-bpp glyphs; Passport uses 12/14/20px 4-bpp glyphs with ASCII fallback.
  The renamed Noto-derived subsets retain OFL 1.1 and are listed in the SBOM.
- Note setup step 3 has separate `Portal closes` and `after 10 min` lines.
  An additional width regression found the existing account-password notice
  exceeded its right column (180px in a 146px space); it now reads `No password`
  / `on this device.` in English, with complete localized equivalents.
- Passport keeps the black root, vector arrows and bounded LVGL pool, and
  increases its rounded/clipped surface radius from 24px to 28px.

No whole-NVS erase, protected identity/Recovery access, eFuse operation,
cache-schema migration, repository publication or service upload is performed.

## Automated and browser evidence

- Core sanitizers, ten Python firmware-verifier cases, catalog printf-signature
  checks, UTF-8 malformed/truncated bounds, four-language lookup/cycling and
  exhaustive glyph coverage passed.
- Real config implementation with an NVS test double passed old-blob migration,
  four-language save/reload, byte-identical original settings, absent/invalid/
  wrong-type fallback, invalid input, and read/write/commit failure handling.
  This is not a physical brownout/durability test.
- Actual Note canvas tests verify all CJK glyph pixels and inverse selection,
  plus fixed-column provisioning/link text widths in all four languages.
- Real LVGL 9.5 with the product 64 KiB pool checks compact text metrics,
  glyph descriptors/line heights, black exterior corner pixels with overflowing
  content, and both inset arrow regions. It does not certify physical legibility.
- Browser tests used the actual embedded assets with local public-only JSON
  fixtures for both product names. Desktop 1280x800 and mobile 390x844 layouts
  were inspected. English default, all four language selections, complete URLs,
  version 0.0.1, localized success page and vertical scrolling passed. Mobile
  document width stayed 390px; About card occupied x=16..374, without horizontal
  overflow. Final test tab reported no warning/error console entries.
- Browser testing also found and fixed a scan/language race: a pending scan now
  reads the current language when its result arrives. Late project metadata
  cannot override a language the user has already chosen.
- These browser checks are fixture-backed UI tests, not device-hosted captive
  portal/network-save end-to-end acceptance. No phone/Mac network was changed.
