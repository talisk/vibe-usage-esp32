# Photo-driven UI fixes — 0.1.2 / 2026-09-05

This continuation supersedes the current UI status in the
[0.1.1 authenticated bring-up](2026-09-05-authenticated-bringup.md). The earlier
hardware matrix remains open where no new matching evidence is recorded.

## Scope

User-supplied physical photos revealed Passport wrapping/overlap, missing
separator glyphs, NOTE4 chart/text overlap, and misleading seven-day state.
Source review also found that NOTE4 could not browse beyond eight sources.
The user separately fixed Today=0 at the uploader; that incident is not treated
as a firmware aggregation defect. Personal photos and usage values are not
copied into the repository or fixtures.

Version 0.1.2 fixes:

- bounded single-line Passport fields and explicit multi-line text boxes;
- separate header/footer/table columns with real 12px/14px font measurements;
- ASCII separators, and compact P/E units for the uint64 upper range;
- NOTE4 bars below labels and counts, not drawn over them;
- source scrolling with edge navigation, count clamping and reset on Today/7D;
- independent selected-window Ready/Empty/Stale and separate Today/7D status.

No authentication, Wi-Fi, cache-schema, partition, or Recovery migration is
included. Cache schema remains 2; auth/settings remain schema 1.

## Automated evidence

The ASan/UBSan core suite covers complete nonempty 7D with empty Today,
incomplete 7D, a complete empty week, and list offsets/counts 0–12 with six/eight
visible rows. Existing parsing, date-range, cache and integer tests also pass.
The ten Python firmware-layout tests pass.

`tools/test-ui-layout.sh` builds the locked real LVGL library on the host and
uses the same bounded-label helper as Passport. It checks the photo's numeric
format, maximum percentage, large-unit format, header, timezone, battery,
footer and status widths, and verifies that long text/newlines cannot increase
single-line label height. A first run caught a 132px status string in a 128px
column; the compact status wording corrected it and the final run passes.

This is a real LVGL label/font test, not a full-board screen emulator, pixel
quality judgment, or proof of all possible UI inputs. Host list tests exercise
navigation policy, not physical button electronics. Local CI syntax checks do
not constitute a remote workflow run.
