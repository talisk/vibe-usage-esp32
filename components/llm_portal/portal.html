API 配置说明 / API setup guide
  1. 在服务商控制台创建 API Key，并确认账户已开通所选 Chat 与 ASR 模型。SiliconFlow 中国站与海外站应选择创建该 Key 的对应站点。 / Create a provider API key and choose the SiliconFlow region where that key was created.
  2. 选择预设后检查完整 Endpoint 和 Model。预设只提供推荐值；模型下线或账户无权限时，请按服务商当前模型列表修改。 / Verify both endpoints and models against the provider's current model list.
  3. Chat Key 与 ASR Key 独立保存。同一服务使用同一个 Key 时也要在两个输入框分别填写；不同服务可分别填写不同 Key。 / Chat and ASR keys are independent; enter the same key twice when one account serves both APIs.
  4. SiliconFlow 使用 multipart WAV；OpenRouter 默认使用 Base64 JSON。遇到兼容服务要求不同格式时手工覆盖上传格式。 / Override the upload format only when a compatible service requires it.

Codex 网关配置说明 / Codex gateway setup
  1. 在同一局域网的常在线 macOS/Linux 主机、NAS 或树莓派上，按仓库 services/codex_gateway/README.zh_CN.md 安装指定版本的 Codex CLI、Python 和依赖。 / Prepare an always-on host by following the repository gateway README.
  2. 运行 codex login --device-auth，在手机或电脑浏览器输入授权码完成 ChatGPT 登录。授权码只用于登录，主机仍需持续运行网关。 / Complete device authorization in a browser; the gateway host must remain online afterward.
  3. 从仓库根目录启动网关并生成专用 Key： / Start the gateway from the repository root and create its dedicated key:
python -m services.codex_gateway.gateway \
  --host 192.168.1.10 --port 8765 \
  --token-file ~/.config/vibe-codex-gateway/token \
  --create-token

将 192.168.1.10 换成主机的私有 IPv4 地址，把 token 文件内容填入“网关专用 Key”。不要填写 ChatGPT 密码、授权码、订阅令牌或 Platform API Key。设备、配置手机与网关主机必须能够互相访问。 / Use the host's private IPv4 address and the generated token file. Never enter account credentials or an authorization code as the gateway key.

Endpoint 格式与隐私说明

Chat 接口支持 OpenAI /v1/chat/completions JSON。语音识别支持 multipart WAV 和 Base64 WAV JSON 两种上传方式。Provider 预设会填写完整接口、推荐模型和 Auto 上传格式；自定义配置可以逐项修改。

云服务使用 HTTPS；局域网模型可使用 http://192.168.1.10:8000/v1/chat/completions 等 RFC1918 IPv4 地址。HTTP 不支持域名、IPv6 或公网地址。URL 不得包含用户名密码、查询参数或片段。设备不会跟随重定向。

启用并发起语音命令后，录音发送到 ASR 服务；识别文字及当前待办发送到 Chat 服务。使用 Codex 网关时，这些数据由电脑转交给对应服务。Key 仅用于对应请求，配置页面不会读回已保存的 Key。 / Voice requests send audio to ASR and the transcript and current tasks to Chat. The Codex gateway forwards these data from your computer. Saved keys are never returned to this page.

更改 Endpoint 后，留空会在保存时清除该服务的旧 Key。保持原 Endpoint 时，留空仍保留原 Key。 / After changing an endpoint, leaving its key blank clears the previous key on Save. With the original endpoint unchanged, a blank key still preserves it.
